# Wildcards

Plain text lists for **🎲LC Wildcard**.

- One entry per line
- Lines starting with `#` are ignored
- Empty lines are skipped
- No `__keyword__` syntax — pick a file in the dropdown; the node returns one random line (seed-stable)

Add your own `.txt` files here (any subfolders), then **restart ComfyUI** so the dropdown refreshes.
